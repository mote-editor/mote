# Contributing to mote

Thank you for your interest in mote! We want to keep this editor lightweight and maintainable.

## 1. General Principles
- **Core Logic Must Use The Standard Python Library:** All core logic should use the Python Standard Library.
- **Human in the Loop:** Every contribution must be understood and verified by a human.

## 2. AI Usage Policy
We follow a "Responsible Use" policy for AI-assisted development (e.g., Copilot, Cursor, Gemini, ChatGPT). 

### The Rule of Responsibility
You are the **Sole Responsible Author** for your submission. If you use AI to generate code, you must be able to explain the logic of every line. "The AI wrote it" is not an acceptable response to code review feedback.
By submitting code you warrant that AI generated code does not violate any 3rd party licenses.

### AI Levels of Disclosure
When opening a Pull Request, please disclose your AI usage based on the following levels:
- **Level 0:** No AI used. (Artisanal, human-only code).
- **Level 1:** AI used for brainstorming or refactoring suggestions only.
- **Level 2:** AI used for boilerplate, regex, or minor helper functions.
- **Level 3:** Significant logic or algorithms were generated by AI and verified by you.
- **Level 4:** Entirely generated by AI.
We do not allow Level 4 contributions

### Attribution (The Git Trailer)
If your contribution is Level 2 or higher, please add the following line to the end of your commit message:
`Assisted-by: [AI Tool Name]`

## 3. Pull Request Checklist
- [ ] I have manually verified and tested this code.
- [ ] I have disclosed the AI Usage Level in the PR description.
